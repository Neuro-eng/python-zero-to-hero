How to Remember What You Learn

Reading is not learning. Using what you read is learning. Follow these five simple rules.

The 5 rules

  1. Test yourself. Close the page. Write the code from memory. If you get stuck, peek, then try again. This is the best way to remember.
  2. Review on a schedule. Look at each lesson again after 1, 3, 7, 14 and 30 days. This site helps you: tick "Mark as complete", and it will show a ↻ Review reminder on the day you should look again.
  3. Explain it in simple words. Say it out loud in English, as if teaching a friend. If you cannot explain it, you do not know it yet. This also improves your speaking.
  4. Keep a mistake notebook. For every error write three lines: What happened. Why. How I fixed it. Mistakes you write down are mistakes you do not repeat.
  5. Build something small. After each module, make one tiny program with no help. Building makes memory strong.

Move up one step at a time.

When you are stuck

  • Wait 15 minutes. Try. Read the error from the bottom line up.
  • Print values to see what is really happening.
  • Write the problem in one sentence. Often the answer appears.
  • Still stuck? Search the error message, then ask a friend or an online community, showing your code and the error.

import random
import string


def factorial(n):
    if n < 0:
        raise ValueError("n must be >= 0")
    return 1 if n in (0, 1) else n * factorial(n - 1)


def fibonacci(n):
    seq = []
    a, b = 0, 1
    for _ in range(n):
        seq.append(a)
        a, b = b, a + b
    return seq


def is_palindrome(text):
    cleaned = "".join(ch.lower() for ch in text if ch.isalnum())
    return cleaned == cleaned[::-1]


def generate_password(length=12):
    if length < 8:
        raise ValueError("length must be at least 8")
    chars = string.ascii_letters + string.digits + "!@#$%^&*"
    return "".join(random.choice(chars) for _ in range(length))

from collections import Counter, defaultdict


def word_count(text):
    words = [w.strip(".,!?;:").lower() for w in text.split()]
    return dict(Counter(w for w in words if w))


def remove_duplicates(items):
    seen = set()
    result = []
    for item in items:
        if item not in seen:
            seen.add(item)
            result.append(item)
    return result


def group_by_length(words):
    groups = defaultdict(list)
    for w in words:
        groups[len(w)].append(w)
    return dict(groups)


def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target - n], i]
        seen[n] = i
    return []

Module 4B: Core Concepts Supplement

Remember it
  • In one line: Some things can change after you make them. Some cannot.
  • Think of it like: mutable = pencil, immutable = pen.
  • Don't forget: b = a does not copy a list. Both names point to the same list.

Fills the gaps beginners hit in interviews: mutability, scope, truthiness, strings, copying, complexity.

Concepts

  • Mutable (list, dict, set) vs immutable (int, str, tuple, frozenset)
  • Scope (LEGB): Local, Enclosing, Global, Built-in
  • Truthiness: 0, "", [], {}, None are falsy
  • Strings: split, join, strip, replace, find, startswith, slicing s[::-1], f-string formats {x:.2f}, {n:,}
  • Copying: assignment shares the object; .copy() is shallow; copy.deepcopy() is deep
  • Complexity: list index O(1), list in O(n), set/dict lookup O(1) average, sort O(n log n)

Practice (easy to hard)

  1. Print the type and truthiness of 0, "", [], None, "0".
  2. Reverse a string with slicing.
  3. Count vowels in a sentence.
  4. Title-case a sentence and strip extra spaces.
  5. Format 1234567.891 as 1,234,567.89.
  6. Show that appending to a list inside a function changes the caller's list.
  7. Fix the mutable default argument bug def f(x, items=[]).
  8. Copy a nested list shallow vs deep and show the difference.
  9. Check whether two strings are anagrams.
  10. Time x in list vs x in set for 100,000 items.

Interview questions

  1. Mutable vs immutable: examples and why it matters?
  2. What is the mutable default argument trap?
  3. Shallow vs deep copy?
  4. Explain LEGB.
  5. Why is set lookup faster than list lookup?

import copy
import time

# 1. Mutability
a = [1, 2]
b = a
b.append(3)
print("shared list:", a)          # [1, 2, 3]
s = "hi"
print("string methods create new strings:", s.upper(), s)

# 2. Mutable default trap and fix
def bad(x, items=[]):
    items.append(x)
    return items

def good(x, items=None):
    items = [] if items is None else items
    items.append(x)
    return items

print(bad(1), bad(2))             # [1, 2] - shared!
print(good(1), good(2))           # [1] [2]

# 3. Shallow vs deep copy
nested = [[1, 2], [3]]
shallow, deep = nested.copy(), copy.deepcopy(nested)
nested[0].append(99)
print("shallow:", shallow, "deep:", deep)

# 4. Scope
x = "global"
def outer():
    x = "enclosing"
    def inner():
        return x
    return inner()
print("LEGB:", outer(), x)

# 5. Strings
text = "  Python makes automation easy  "
print(text.strip().title(), "|", "-".join(text.split()), "|", text.strip()[::-1])
print(f"{1234567.891:,.2f}", f"{0.256:.1%}")

# 6. Truthiness
for v in [0, "", [], None, "0", [0]]:
    print(repr(v), bool(v))

# 7. Complexity
data = list(range(100_000)); lookup = set(data)
t = time.perf_counter(); 99_999 in data; t1 = time.perf_counter() - t
t = time.perf_counter(); 99_999 in lookup; t2 = time.perf_counter() - t
print(f"list: {t1:.6f}s  set: {t2:.6f}s")

import math


class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Deposit must be positive")
        self._balance += amount

    def withdraw(self, amount):
        if amount > self._balance:
            raise ValueError("Insufficient funds")
        self._balance -= amount


class Shape:
    def area(self):
        raise NotImplementedError


class Circle(Shape):
    def __init__(self, r):
        self.r = r

    def area(self):
        return math.pi * self.r ** 2


class Rectangle(Shape):
    def __init__(self, w, h):
        self.w, self.h = w, h

    def area(self):
        return self.w * self.h

import asyncio
import functools
import time
from contextlib import contextmanager
from itertools import islice

def timer(fn):
    @functools.wraps(fn)
    def wrapper(*a, **kw):
        start = time.perf_counter()
        result = fn(*a, **kw)
        print(f"{fn.__name__} took {time.perf_counter() - start:.4f}s")
        return result
    return wrapper

def retry(times=3):
    def deco(fn):
        @functools.wraps(fn)
        def wrapper(*a, **kw):
            for attempt in range(1, times + 1):
                try:
                    return fn(*a, **kw)
                except Exception as err:
                    print(f"attempt {attempt} failed: {err}")
            raise RuntimeError("all retries failed")
        return wrapper
    return deco

calls = {"n": 0}
@retry(times=3)
@timer
def flaky():
    calls["n"] += 1
    if calls["n"] < 3:
        raise ValueError("temporary error")
    return "ok"
print(flaky())

def make_counter():
    count = 0
    def inc():
        nonlocal count
        count += 1
        return count
    return inc
c = make_counter(); c(); print("closure:", c())

def fib():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b
print(list(islice(fib(), 10)))

@contextmanager
def block_timer(label):
    start = time.perf_counter()
    try:
        yield
    finally:
        print(f"{label}: {time.perf_counter() - start:.4f}s")
with block_timer("sum"):
    sum(range(1_000_000))

@functools.lru_cache(maxsize=None)
def slow_fib(n):
    return n if n < 2 else slow_fib(n - 1) + slow_fib(n - 2)
print(slow_fib(80))

    await asyncio.sleep(delay)
    return f"{name} done"

    print(await asyncio.gather(fetch("A", 0.3), fetch("B", 0.2), fetch("C", 0.1)))

from dataclasses import dataclass
from typing import Optional

logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")

@dataclass
class Item:
    name: str
    price: float
    qty: int = 1

    subtotal = sum(i.price * i.qty for i in items)
    if discount:
        subtotal *= 1 - discount
    return round(subtotal * (1 + TAX_RATE), 2)

        amount = total(items)
        self.storage.save({"amount": amount})
        log.info("order placed amount=%s", amount)
        return amount

import json
from collections import defaultdict
from datetime import date
from pathlib import Path

DB = Path(__file__).with_name("expenses.json")


def load(path=DB):
    try:
        return json.loads(Path(path).read_text(encoding="utf-8"))
    except (FileNotFoundError, json.JSONDecodeError):
        return []


def save(expenses, path=DB):
    Path(path).write_text(json.dumps(expenses, indent=2), encoding="utf-8")


def add_expense(expenses, amount, category, note=""):
    if amount <= 0:
        raise ValueError("Amount must be positive")
    expenses.append(
        {"date": date.today().isoformat(), "amount": amount, "category": category, "note": note}
    )
    return expenses


def summarize(expenses):
    totals = defaultdict(float)
    for e in expenses:
        totals[e["category"]] += e["amount"]
    return dict(totals)


def main():
    p = argparse.ArgumentParser(description="Expense Tracker")
    sub = p.add_subparsers(dest="cmd", required=True)
    a = sub.add_parser("add")
    a.add_argument("amount", type=float)
    a.add_argument("category")
    a.add_argument("note", nargs="?", default="")
    sub.add_parser("list")
    sub.add_parser("summary")
    args = p.parse_args()

    data = load()
    if args.cmd == "add":
        try:

import argparse
import re
from collections import Counter

LOG_RE = re.compile(r"^(\S+) (\S+) ([A-Z]+) (.*)$")


def analyze(lines):
    levels, errors = Counter(), Counter()
    for line in lines:
        m = LOG_RE.match(line.strip())
        if not m:
            continue
        level, msg = m.group(3), m.group(4)
        levels[level] += 1
        if level == "ERROR":
            errors[msg] += 1
    return levels, errors


def main():
    p = argparse.ArgumentParser()
    p.add_argument("logfile")
    args = p.parse_args()
    with open(args.logfile, encoding="utf-8") as f:
        levels, errors = analyze(f)
    print("Levels:", dict(levels))
    print("Top errors:")
    for msg, count in errors.most_common(5):
        print(f"  {count}x {msg}")

    main()

import shutil
from pathlib import Path

CATEGORIES = {
    "Images": {".jpg", ".jpeg", ".png", ".gif", ".webp"},
    "Documents": {".pdf", ".docx", ".txt", ".xlsx", ".pptx"},
    "Code": {".py", ".js", ".html", ".css", ".json"},
    "Archives": {".zip", ".tar", ".gz", ".rar"},
}


def category_for(path):
    ext = Path(path).suffix.lower()
    for name, exts in CATEGORIES.items():
        if ext in exts:
            return name
    return "Other"


def organize(folder, dry_run=False):
    folder = Path(folder)
    moves = []
    for item in folder.iterdir():
        if item.is_file():
            dest_dir = folder / category_for(item)
            moves.append((item, dest_dir / item.name))
    for src, dest in moves:
        print(f"{src.name} -> {dest.parent.name}/")
        if not dry_run:
            dest.parent.mkdir(exist_ok=True)
            if dest.exists():
                dest = dest.with_name(f"{dest.stem}_copy{dest.suffix}")
            shutil.move(str(src), str(dest))
    return moves


if __name__ == "__main__":
    p = argparse.ArgumentParser()
    p.add_argument("folder")
    p.add_argument("--dry-run", action="store_true")
    a = p.parse_args()

def get_json(path, retries=3):
    for attempt in range(1, retries + 1):
        try:
            resp = requests.get(f"{BASE}{path}", timeout=10)
            resp.raise_for_status()
            return resp.json()

import sqlite3
from contextlib import closing

from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

DB_PATH = "todos.db"
app = FastAPI(title="To-do API")


class TodoIn(BaseModel):
    title: str
    done: bool = False


def conn():
    c = sqlite3.connect(DB_PATH)
    c.row_factory = sqlite3.Row
    c.execute("CREATE TABLE IF NOT EXISTS todos (id INTEGER PRIMARY KEY, title TEXT NOT NULL, done INTEGER DEFAULT 0)")
    return c


@app.get("/todos")
def list_todos():
    with closing(conn()) as c:
        return [dict(r) for r in c.execute("SELECT * FROM todos ORDER BY id")]


@app.post("/todos", status_code=201)
def create_todo(todo: TodoIn):
    with closing(conn()) as c:
        cur = c.execute("INSERT INTO todos (title, done) VALUES (?, ?)", (todo.title, int(todo.done)))
        c.commit()
        return {"id": cur.lastrowid, **todo.model_dump()}


@app.put("/todos/{todo_id}")
def update_todo(todo_id: int, todo: TodoIn):
    with closing(conn()) as c:
        cur = c.execute("UPDATE todos SET title=?, done=? WHERE id=?", (todo.title, int(todo.done), todo_id))
        c.commit()
        if cur.rowcount == 0:
            raise HTTPException(404, "Todo not found")
        return {"id": todo_id, **todo.model_dump()}


@app.delete("/todos/{todo_id}", status_code=204)
def delete_todo(todo_id: int):
    with closing(conn()) as c:
        cur = c.execute("DELETE FROM todos WHERE id=?", (todo_id,))
        c.commit()
        if cur.rowcount == 0:
            raise HTTPException(404, "Todo not found")

90-Day Spoken English Plan

Commit to 30 minutes daily. Consistency beats long weekend sessions.

Phase 1 (Days 1-30): Build the habit and the base

  • Speak aloud every day. Shadow 10 minutes of one speaker (see daily_routine.md).

  • Week 1: pronunciation basics (word stress, vowel length, "th", "v/w").
  • Week 2: self-introduction in 60 seconds. Record it; re-record on Day 14.
  • Week 3: describe your day, your college, your hometown, your goals (present, past, future).
  • Week 4: explain a Python concept in 2 minutes (variable, loop, function).
  • Milestone: a 2-minute self-introduction without reading.

  • Learn the PREP and STAR structures (see interview_english.md).

  • Join one speaking partner/club session weekly (online communities, college groups, local meetups).
  • Practice stand-up updates daily (scripts/standup_update.md).

Fluency Techniques

1. Fix filler words ("umm", "like", "you know")

  • Record yourself and count fillers per minute.
  • Replace a filler with a silent pause. Silence sounds thoughtful.
  • Slow down slightly, since fillers appear when you speak faster than you think.
  • Target: below 3 fillers per minute.

2. Speak in chunks, not word by word

Group words in meaning units, with tiny pauses between them:

"I built a tracker | that records my expenses | and shows a monthly summary."

3. Shadowing (the most effective free method)

  1. Pick a 30-second clip with a transcript.
  2. Listen 3 times while reading.
  3. Speak along, 1 second behind the speaker.
  4. Record and compare. Focus on rhythm and stress, not on sounding like someone else.

4. Word stress and sentence stress

  • English is stress-timed: important words are loud, long and clear. Small words are quick and soft.
  • "I WANT to BUILD a WEB app." (stress the content words)
  • Look up stress in an online dictionary and listen to the audio every time.

5. Common pronunciation issues to practice

  • th: think, three, the, this (tongue between teeth)
  • v / w: very / wary, vine / wine
  • Final consonants: say the "d", "t", "s" at the end: worked, tested, tests
  • Schwa (the weak "uh" sound): about, problem, computer

6. Think in English

  • Narrate your actions: "I'm opening the file. Now I'm running the test."
  • Describe what you see for 2 minutes while walking.
  • Do not translate word by word. Learn whole phrases instead.

7. Fix hesitation

  • Have 5 "bridge phrases" ready (see phrase_bank.md).
  • Use simple words. A clear simple sentence beats a complicated broken one.
  • If you make a mistake, correct it once and continue. Don't stop.

8. Listening

  • Daily: 15 minutes of tech podcasts or conference talks.
  • Use English subtitles first, then no subtitles.
  • Write down 3 phrases per day, then use them.

9. Vocabulary

  • Learn words in sentences, not lists.
  • Review with spaced repetition (Anki or similar) for 10 minutes a day.
  • Learn collocations: make a decision, run a test, fix a bug, push code, raise an issue.

10. Get feedback

  • Speaking partner or club once a week.
  • Record weekly and compare Week 1 vs Week 4.
  • Ask one mentor to point out your 2 most common mistakes.

Free resource types to look for

Tech conference talks, TED talks, BBC Learning English, podcasts on software/careers, YouTube channels about interview English, your own recordings. Choose speakers you find clear and easy to follow.

Interview English: Structures and Sample Answers

Two structures to memorize

STAR (for experience questions): Situation, Task, Action, Result PREP (for opinion/technical questions): Point, Reason, Example, Point

1. "Tell me about yourself" (60-90 seconds)

Structure: Present, Past, Future.

"Good morning. My name is ___. I'm a recent graduate in ___ and I'm learning Python development. Over the last few months, I've built six projects, including an expense tracker, a log analyzer and a REST API using FastAPI. I publish all of them on GitHub. I enjoy solving problems with code and automating repetitive tasks. I'm now looking for an entry-level Python role where I can learn from a team and contribute from day one."

2. "Why should we hire you?"

"I'm a fast learner with a strong Python foundation, and I can show it with real projects on GitHub. I communicate clearly, I ask questions early, and I finish what I start. I'd bring energy and discipline to the team."

3. "What are your strengths and weaknesses?"

"My strength is consistency. I practice coding every day and I've committed code for X days in a row. A weakness I'm working on is public speaking. I practice by recording presentations and getting feedback, and it's improving every week."

4. "Describe a challenge you faced" (STAR)

"Situation: In my expense tracker, the app crashed when the JSON file was empty. Task: I needed to make the app reliable. Action: I read the traceback, found the missing error handling, and wrapped file loading in try/except. I also added a test. Result: The crash disappeared and I learned to always test edge cases."

5. Technical questions: sample answers

What is the difference between a list and a tuple?

"A list is mutable, so you can change it after creation. A tuple is immutable. I use tuples for fixed data, like coordinates, and lists for collections that change. Tuples can also be dictionary keys, because they're hashable."

What is a decorator?

"A decorator is a function that takes another function and adds behavior without changing its code. For example, I can write a timer decorator to measure how long a function takes."

What is the difference between == and is?

"== compares values. is checks whether two names point to the exact same object in memory."

What are *args and **kwargs?

"*args collects extra positional arguments into a tuple. **kwargs collects extra keyword arguments into a dictionary."

What is a virtual environment and why use it?

"It's an isolated Python environment for one project, so dependencies don't conflict between projects. I create it with python -m venv."

What is a REST API?

"It's a way for programs to communicate over HTTP using standard methods: GET to read, POST to create, PUT or PATCH to update, DELETE to remove. Data is usually exchanged as JSON."

6. Thinking aloud during coding rounds

  • "Let me restate the problem to make sure I understand."
  • "A simple approach is brute force. It would be O(n squared). Then I'll look for something faster."
  • "I'll use a dictionary here because lookups are O(1)."
  • "Let me test with an edge case: an empty list."
  • "I'd improve this by..."

"I haven't worked with that directly. My understanding is ___. I'd start by reading the documentation and testing a small example."

Honesty plus a learning plan is better than guessing.

How to Present in English (Fluent and Clear)

1. The structure: "Tell them what you'll tell them"

Part Time share What to say
Opening 10% Greet, introduce yourself, topic, why it matters, agenda
Body 75% 2-3 main points, each with an example or data
Closing 15% Summary, key takeaway, next step, thank you, invite questions

Opening template

"Good morning, everyone. My name is ___. Today I'll talk about ___. This matters because ___. I'll cover three things: first ___, second ___, and finally ___."

Closing template

"To summarize: ___, ___, and ___. The key takeaway is ___. Thank you. I'm happy to take any questions."

2. Use PREP for every point

Point, Reason, Example, Point again.

"We should add tests (point) because they catch bugs early (reason). For example, last week a test caught a crash in my login function (example). So, testing saves time (point)."

3. Slide rules

  • One idea per slide, at most 6 lines, large font.
  • Slide title = the message ("Sales grew 30% in Q4"), not a topic ("Sales").
  • Visuals over text. Do not read slides word for word.
  • 1 slide per 1-2 minutes.

4. Delivery: the 5 controls

  1. Pace: about 120-150 words per minute. Slower for key points.
  2. Pause: stop for 1-2 seconds after each important sentence. Silence sounds confident.
  3. Stress: emphasize key words ("sales GREW thirty percent").
  4. Intonation: voice goes down at the end of statements, up for yes/no questions.
  5. Body language: eye contact (or look at the camera), open posture, calm hands.

5. Online presentations

  • Camera at eye level, good light, quiet room, mic test.
  • Share only the needed window, close notifications.
  • Check in: "Can everyone see my screen?" and "Any questions so far?"

6. Handling Q&A

  1. Listen fully. Do not interrupt.
  2. Paraphrase: "So you're asking whether..."
  3. Answer in 2-3 sentences using PREP.
  4. Check: "Does that answer your question?"
  5. If you don't know: "I don't know that yet, but I'll check and get back to you by tomorrow."

7. Handling nerves

  • Practice the first 30 seconds until it is automatic.
  • Breathe in for 4 seconds, out for 6, before you start.
  • It is OK to pause and look at your notes. Say: "Let me check my notes for a second."
  • Nervousness is normal. Listeners notice it far less than you think.

8. Rehearsal plan

  1. Write bullet points, not a full script.
  2. Speak it aloud alone, 3 times.
  3. Time it, and cut 10%.
  4. Record, review, fix.
  5. Present to one friend and ask for 2 honest comments.

Useful verbs for IT work

build, implement, deploy, debug, refactor, optimize, integrate, migrate, automate, monitor, review, merge, roll back, escalate, troubleshoot

Common mistakes

  • "I have 22 years" -> "I'm 22 years old."
  • "I am having a doubt" -> "I have a question."
  • "Do the needful" -> "Please take the necessary action."
  • "Revert back" -> "Reply" (or revert to mean undo a change)
  • "Prepone" -> "Move earlier."
  • "Out of station" -> "Out of town."
  • "I will explain you" -> "I will explain it to you."
  • "Discuss about" -> "Discuss" (no "about")

Script: Explaining a Problem or Incident

What happened: "At 10:15, our API started returning errors for some users." Impact: "About 5% of requests failed for 20 minutes." Cause: "A configuration change set the wrong database timeout." Fix: "We rolled back the change and the service recovered at 10:35." Prevention: "We'll add a test and a review step for configuration changes."

Tone

Calm, factual, no blaming: say "the change caused" not "he caused".

Script: Speaking Up in Meetings

Join the conversation - "Can I add something here?" - "If I may, I'd like to share a quick thought."

Ask for clarity - "Just to be sure I understand, you want ___, correct?" - "Could you share an example?"

Suggest an idea - "What if we try ___?" - "One option could be ___. The benefit is ___."

Give a status - "I'm on track to deliver by Friday." - "I'd need two more days because ___."

Close a topic - "So, to summarize, we agreed on ___. I'll take the action on ___ by ___."

Script: Project Demo (3 minutes)

  1. Hook (15 s): "Have you ever lost track of where your money goes? I built a tool to fix that."
  2. Problem (20 s): What problem does it solve and for whom?
  3. Solution (30 s): One sentence on what it does and the tech used (Python, JSON, argparse).
  4. Live demo (60 s): Show 2-3 actions. Narrate: "Now I'm adding an expense... as you can see, the summary updates."
  5. Challenge (25 s): "The hardest part was ___. I solved it by ___."
  6. Result and next steps (20 s): "Next I plan to add ___."
  7. Close (10 s): "Thank you. Happy to take questions."

Language to use

  • "The goal of this project is..."
  • "Let me show you how it works."
  • "Under the hood, it uses..."
  • "One thing I'm proud of is..."
  • "If I had more time, I would..."

Method (say it aloud in interviews)

  1. Restate the problem and examples.
  2. Ask about edge cases (empty input, negatives, duplicates).
  3. Explain a brute-force solution and its complexity.
  4. Improve it.
  5. Code, then test with examples.
  6. State time and space complexity.

Speaking Practice Tracker

Logs your daily English practice and shows your streak. Save this as speaking_tracker.py, then run python speaking_tracker.py log 20 "Shadowing" and python speaking_tracker.py stats.

speaking_tracker.py
"""Log daily English-speaking practice and see your streak.

Usage:
    python tools/speaking_tracker.py log 20 "Shadowing + self intro"
    python tools/speaking_tracker.py stats
"""
import argparse
import json
from datetime import date, timedelta
from pathlib import Path

DB = Path(__file__).resolve().parent.parent / "english" / "practice_log.json"


def load(path=DB):
    try:
        return json.loads(Path(path).read_text(encoding="utf-8"))
    except (FileNotFoundError, json.JSONDecodeError):
        return []


def save(entries, path=DB):
    Path(path).write_text(json.dumps(entries, indent=2), encoding="utf-8")


def log_entry(entries, minutes, note="", day=None):
    if minutes <= 0:
        raise ValueError("minutes must be positive")
    entries.append({"date": (day or date.today()).isoformat(), "minutes": minutes, "note": note})
    return entries


def current_streak(entries, today=None):
    today = today or date.today()
    days = {e["date"] for e in entries}
    streak, d = 0, today
    if d.isoformat() not in days:  # allow the streak to continue if today isn't logged yet
        d -= timedelta(days=1)
    while d.isoformat() in days:
        streak += 1
        d -= timedelta(days=1)
    return streak


def stats(entries, today=None):
    total = sum(e["minutes"] for e in entries)
    days = len({e["date"] for e in entries})
    return {
        "total_minutes": total,
        "days_practiced": days,
        "average_per_day": round(total / days, 1) if days else 0,
        "current_streak": current_streak(entries, today),
    }


def main():
    p = argparse.ArgumentParser(description="English speaking practice tracker")
    sub = p.add_subparsers(dest="cmd", required=True)
    lg = sub.add_parser("log")
    lg.add_argument("minutes", type=int)
    lg.add_argument("note", nargs="?", default="")
    sub.add_parser("stats")
    args = p.parse_args()

    entries = load()
    if args.cmd == "log":
        try:
            save(log_entry(entries, args.minutes, args.note))
            print("Logged. Keep going!")
        except ValueError as err:
            print("Error:", err)
    else:
        for k, v in stats(entries).items():
            print(f"{k.replace('_', ' ').title():<20}{v}")


if __name__ == "__main__":
    main()

Words-per-Minute Calculator

Checks your speaking pace against a script. Save as wpm_calculator.py and run python wpm_calculator.py my_script.txt 90 (90 seconds). Aim for about 120-150 words per minute.

wpm_calculator.py
"""Words-per-minute calculator for your presentation script.

Usage:
    python tools/wpm_calculator.py my_script.txt 90
Target pace for clear presentations: about 120-150 WPM.
"""
import sys
from pathlib import Path


def words_per_minute(text, seconds):
    if seconds <= 0:
        raise ValueError("seconds must be positive")
    return round(len(text.split()) / (seconds / 60), 1)


def pace_feedback(wpm):
    if wpm < 100:
        return "Slow: add energy, trim long pauses."
    if wpm <= 160:
        return "Good pace for presenting."
    return "Fast: slow down and pause after key points."


def main():
    if len(sys.argv) != 3:
        print(__doc__)
        return
    text = Path(sys.argv[1]).read_text(encoding="utf-8")
    wpm = words_per_minute(text, float(sys.argv[2]))
    print(f"{wpm} words per minute. {pace_feedback(wpm)}")


if __name__ == "__main__":
    main()
