# Self-Review Checklist for Recordings

Score each item from 1 (weak) to 5 (strong). Re-test every 2 weeks.

| Area | Question | Score |
|------|----------|-------|
| Structure | Clear opening, 2-3 points, clear closing? | |
| Clarity | Could a beginner follow it? | |
| Pace | Around 120-150 words per minute? | |
| Pauses | Did I pause instead of using fillers? | |
| Fillers | Fewer than 3 per minute? | |
| Stress | Key words emphasized? | |
| Pronunciation | Tech words correct? | |
| Confidence | Voice steady, not rushed? | |
| Examples | At least one concrete example? | |
| Energy | Sounded interested, not flat? | |

## After each review
- Best thing I did: ______
- One thing to fix next time: ______
- Phrase to practice: ______

Track the trend, not perfection.
