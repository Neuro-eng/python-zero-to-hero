# Script: Daily Stand-up (30 seconds)

> **Yesterday** I ___ (finished the login API / fixed the date bug).
> **Today** I'm going to ___ (write tests / start the report page).
> **Blockers:** I'm stuck on ___ / I don't have any blockers.

## Examples
> "Yesterday I finished the user registration endpoint and wrote three tests. Today I'll work on password validation. I have no blockers."

> "Yesterday I investigated the failing deployment. I found a missing environment variable. Today I'll fix it and update the docs. I need access to the staging server."

## Useful phrases
- "I'm making good progress on..."
- "I'm slightly behind because..., but I expect to finish by..."
- "Could someone review my pull request?"
