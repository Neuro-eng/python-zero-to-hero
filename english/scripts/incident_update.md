# Script: Explaining a Problem or Incident

> **What happened:** "At 10:15, our API started returning errors for some users."
> **Impact:** "About 5% of requests failed for 20 minutes."
> **Cause:** "A configuration change set the wrong database timeout."
> **Fix:** "We rolled back the change and the service recovered at 10:35."
> **Prevention:** "We'll add a test and a review step for configuration changes."

## Tone
Calm, factual, no blaming: say "the change caused" not "he caused".
