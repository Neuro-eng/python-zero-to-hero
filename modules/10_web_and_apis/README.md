# Module 10: Web and APIs

## Concepts
- HTTP: methods (GET, POST, PUT, DELETE), status codes (200, 201, 400, 404, 500)
- JSON
- `requests` library: `get`, `post`, headers, params, timeouts
- Error handling for network failures
- Rate limits and API keys (keep them in environment variables, never in Git)

## Practice
1. Call a public API and print a clean summary.
2. Handle timeouts and non-200 responses.
3. Build **Project 4: API client**.

## Interview tip
Be ready to explain: "What happens when you type a URL in the browser?"
