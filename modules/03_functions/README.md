# Module 03: Functions

## Concepts
- `def`, parameters, return values
- Default and keyword arguments, `*args`, `**kwargs`
- Scope (local vs global)
- Lambda, `map`, `filter`, `sorted(key=...)`
- Docstrings and type hints

## Practice
1. `factorial(n)` (iterative and recursive).
2. `fibonacci(n)` returns the first n numbers.
3. `is_palindrome(text)` ignoring case and spaces.
4. `generate_password(length)` with letters, digits and symbols.
