# Module 09: Testing and Debugging

## Concepts
- `pytest`: test functions, `assert`, `pytest.raises`, `parametrize`, fixtures
- Debugging: read the traceback bottom-up, `print`, `breakpoint()` (pdb), IDE debugger
- Common errors: `NameError`, `TypeError`, `KeyError`, `IndexError`
- Edge cases: empty input, zero, negative numbers, wrong type

## Practice
1. Run `pytest -q` from the repo root and read the output.
2. Write 5 tests for your own function, including 2 edge cases.
3. Deliberately break a function and use `breakpoint()` to find the bug.

## Speak it
Describe a bug you fixed using: **Problem, Cause, Fix, Lesson**.
