# Module 05: Object-Oriented Programming

## Concepts
- Classes, objects, `__init__`, `self`
- Attributes and methods, `__str__`, `__repr__`
- Inheritance, `super()`, polymorphism
- Encapsulation (`_protected`, properties)
- Dataclasses

## Practice
1. `BankAccount` with deposit, withdraw (no overdraft), balance.
2. `Shape` base class with `Circle` and `Rectangle` area.
3. Convert a class to a `@dataclass`.

## Speak it
Explain "class vs object" with a real-life example (car blueprint vs a car).
