# Module 08: Automation with the Standard Library

## Concepts
- `pathlib`, `os`, `shutil` (files and folders)
- `re` (regular expressions)
- `datetime`, `argparse` (command-line tools)
- `subprocess`, `logging`
- Scheduling: cron (Linux/macOS), Task Scheduler (Windows)

## Practice
1. `extract_emails(text)` using regex.
2. `parse_log_line(line)` returns a dict.
3. `organize_by_extension(folder)` moves files into subfolders (see Project 3).

## Why employers care
Automating boring work (reports, file cleanup, log checks) is a top real-world use of Python.
