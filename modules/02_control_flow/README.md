# Module 02: Control Flow

## Concepts
- `if / elif / else`
- `for` loops with `range()`, `while` loops
- `break`, `continue`
- Truthy and falsy values

## Practice
1. FizzBuzz for 1..n (return a list of strings).
2. Check whether a number is prime.
3. Sum of digits of an integer.
4. Number guessing game (see examples).

## Speak it
Describe the FizzBuzz logic in English in 30 seconds. Use *"first, then, finally"*.
