# Module 04: Data Structures

## Concepts
- `list`, `tuple`, `set`, `dict`
- Slicing, methods, sorting
- Comprehensions: `[x*x for x in nums if x % 2 == 0]`
- `collections`: `Counter`, `defaultdict`, `deque`

## Practice
1. `word_count(text)` returns a dict of word frequencies.
2. `remove_duplicates(items)` keeps order.
3. `group_by_length(words)` returns a dict of length to words.
4. `two_sum(nums, target)` returns indices (classic interview question).
