# Module 01: Basics

**Goal:** write and run simple programs.

## Concepts
- Running Python: `python file.py`
- Variables and types: `int`, `float`, `str`, `bool`
- `print()`, `input()`, f-strings
- Operators: `+ - * / // % **`, comparison, `and or not`
- Type conversion: `int("5")`, `str(5)`

## Practice (see `solutions.py` only after trying)
1. Convert Celsius to Fahrenheit: `F = C * 9/5 + 32`.
2. Given a bill and tip percentage, return the total.
3. Swap two variables without a third variable.
4. Write `is_even(n)`.

## Speak it
Explain out loud: *"A variable is a name that points to a value."*
