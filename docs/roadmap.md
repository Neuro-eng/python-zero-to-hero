# 16-Week Roadmap: Zero to Job-Ready

Assumes about 2 hours per day, 6 days per week. Take 1 rest day.

| Week | Python focus | Project / output | English focus |
|------|--------------|------------------|---------------|
| 1 | Module 01: variables, types, input/output | Tip calculator | Pronounce the alphabet and tech terms; 2-minute self-introduction |
| 2 | Module 02: if/else, loops | Number guessing game | Shadowing 10 min daily; learn 10 phrases/day |
| 3 | Module 03: functions | Password generator | Describe your day in the past tense |
| 4 | Module 04: list, dict, set, tuple, comprehensions | Contact book | First recording: "Tell me about yourself" |
| 5 | Module 05: OOP | Bank account classes | Explain a concept (class vs object) in 2 minutes |
| 6 | Module 06: files, JSON, exceptions | **Project 1: Expense Tracker** | Present your project in 3 minutes |
| 7 | Module 07: venv, pip, Git, GitHub | Push all work to GitHub | Write a README in English; read it aloud |
| 8 | Module 08: automation (os, pathlib, regex) | **Project 2/3: Log Analyzer, File Organizer** | Stand-up update scripts |
| 9 | Module 09: pytest, debugging | Add tests to projects | Explain a bug you fixed |
| 10 | Module 10: requests, APIs, JSON | **Project 4: API client** | Mock demo with a friend |
| 11 | Module 11: pandas, matplotlib | **Project 5: Sales analysis** | Present charts: describe trends |
| 12 | Module 12: FastAPI, SQL (SQLite) | **Project 6: To-do REST API** | Technical walkthrough (5 min) |
| 13 | Data structures and algorithms (easy) | 30 easy problems | Think aloud while solving |
| 14 | Resume, LinkedIn, GitHub polish | Portfolio ready | HR interview round practice |
| 15 | Mock interviews (technical + HR) | Record 3 mock interviews | Review recordings; fix filler words |
| 16 | Apply: 5-10 applications/day, referrals | Track in a spreadsheet | Follow-up emails, salary conversation |

## Checkpoints

- **End of week 6:** can build a small CLI app alone.
- **End of week 12:** can build and test a REST API.
- **End of week 16:** 6 projects on GitHub, 3 mock interviews done, applications sent.

## Weeks 17-30: Professional track (optional but recommended for backend roles)

| Phase | Weeks | Modules | Goal |
|-------|-------|---------|------|
| 1. Beginner Python | 1-4 | 01-04 and **4B** | Write programs independently |
| 2. Intermediate Python | 5-9 | 05-09 | Build apps with OOP, files, Git and tests |
| 3. Advanced Python | 17-19 | **13** Advanced Python, **14** Professional Python | Write clean, professional-quality code |
| 4. Backend development | 20-26 | 10, 12, then **15** Advanced Databases, **16** Advanced Backend | Build production-style APIs with a database and login |
| 5. Deployment | 27-30 | **17** Deployment and DevOps | Ship and maintain a live application |

**Per-topic study method:** read the concept, type 5 examples, solve the 10 practice questions yourself, answer the interview questions out loud in English, then build the mini-project. Read solutions only after you try.
