# One-Page Resume Guide (Fresher)

## Structure
1. **Header:** Name, phone, email, city, GitHub, LinkedIn (no photo, no date of birth needed)
2. **Summary (2 lines):** "Python developer with hands-on experience in automation, REST APIs and data analysis. Built 6 projects (GitHub link)."
3. **Skills:** Python, FastAPI, SQL/SQLite, pandas, Git/GitHub, pytest, Linux basics, REST APIs
4. **Projects (most important):** 3-4 projects, 2-3 bullets each
5. **Education:** degree, college, year, CGPA/percentage
6. **Certifications:** PCEP, HackerRank badges, etc.

## Project bullet formula
**Action verb + what you built + tech + result**
- "Built a REST API with FastAPI and SQLite supporting full CRUD; documented with OpenAPI and tested with pytest."
- "Automated file sorting for 1,000+ files using pathlib and argparse, with a dry-run safety mode."
- "Analyzed 480 sales records with pandas; identified top region and product, visualized monthly trends."

## Rules
- One page. PDF format. File name: `FirstName_LastName_Python_Developer.pdf`.
- Match keywords from the job description (honestly).
- No grammar mistakes: read it aloud and have a friend check it.
- Every link must open.
