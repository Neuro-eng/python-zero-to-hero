# GitHub and LinkedIn

## GitHub
- Pin 4-6 best repos, each with: clear README, screenshot or demo, setup steps, tests.
- Commit regularly: small commits, clear messages.
- Add a profile README: who you are, skills, projects, how to reach you.
- Use `.gitignore`; never commit passwords or API keys.

## README template
```
# Project name
One-line description.
## Features
## Tech stack
## Setup
## Usage / Screenshots
## What I learned
```

## LinkedIn
- Photo: clear, plain background, smiling.
- Headline: "Python Developer | FastAPI | SQL | Automation | Open to work", not just "Student".
- About: 4-5 lines, who you are, what you build, what you want.
- Featured: GitHub projects, resume.
- Post weekly: "I built X. Here's what I learned." Posting in English improves both visibility and fluency.
- Connect with recruiters, engineers and alumni with a personal note:
  > "Hi ___, I'm a Python developer exploring entry-level roles. I'd love to connect and learn from your experience at ___."
- Ask for referrals politely, with your resume and a specific job link.
