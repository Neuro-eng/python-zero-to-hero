# Python and General Interview Questions

## Python basics
1. What are Python's key features? (interpreted, dynamically typed, readable, large ecosystem)
2. Mutable vs immutable types?
3. List vs tuple vs set vs dict?
4. What is a list comprehension?
5. `==` vs `is`?
6. What is `None`?
7. What are `*args` and `**kwargs`?
8. Explain scope (LEGB rule).
9. What is a lambda?
10. Shallow copy vs deep copy?

## Intermediate
11. What is a decorator?
12. What is a generator? `yield` vs `return`?
13. What is the GIL?
14. How does exception handling work? `finally`?
15. What are context managers (`with`)?
16. What is `__name__ == "__main__"`?
17. Explain `@staticmethod`, `@classmethod` and instance methods.
18. What is inheritance? Multiple inheritance? MRO?
19. What are dunder methods? Examples.
20. How does Python manage memory (reference counting, garbage collection)?

## Practical
21. How do you read a large file efficiently? (iterate line by line)
22. How do you handle JSON data?
23. How do you make an HTTP request and handle errors?
24. How do you structure a project?
25. How do you manage dependencies? (venv, requirements.txt, pip)
26. How do you test your code? (pytest)
27. How do you debug? (traceback, logging, pdb)
28. What is PEP 8?
29. What are type hints? Benefits?
30. How do you use environment variables for secrets?

## SQL and web
31. SELECT, WHERE, GROUP BY, HAVING, ORDER BY, JOIN types?
32. Primary key vs foreign key?
33. What is an index?
34. REST: what are the HTTP methods and status codes?
35. PUT vs PATCH?
36. What is JSON? What is an API?
37. FastAPI vs Flask vs Django: when to use which?

## Git and tools
38. `git merge` vs `git rebase`?
39. What is a pull request?
40. How do you resolve a merge conflict?
41. Basic Linux commands: `ls`, `cd`, `grep`, `cat`, `chmod`.

## HR and behavioral
42. Tell me about yourself.
43. Why Python / why IT?
44. Describe your best project and the hardest bug.
45. Strengths and weaknesses.
46. Where do you see yourself in 3 years?
47. How do you handle deadlines and pressure?
48. Tell me about a time you worked in a team.
49. Why should we hire you?
50. Do you have any questions for us?

Practice answering each **out loud in English** in 60-90 seconds. Record, review, repeat.
