# Easy Data Structures and Algorithms Practice

Focus on patterns, not volume. Aim for about 30 easy problems before interviews.

| Topic | Problems |
|-------|----------|
| Arrays/lists | Two sum, max subarray (Kadane), merge sorted lists, rotate list |
| Strings | Palindrome, anagram check, reverse words, first non-repeating character |
| Hash maps | Word frequency, group anagrams, longest consecutive sequence |
| Stack/queue | Valid parentheses, min stack, queue using stacks |
| Search/sort | Binary search, bubble/merge sort basics |
| Recursion | Factorial, fibonacci, power function |
| Linked list | Reverse list, detect cycle |

## Method (say it aloud in interviews)
1. Restate the problem and examples.
2. Ask about edge cases (empty input, negatives, duplicates).
3. Explain a brute-force solution and its complexity.
4. Improve it.
5. Code, then test with examples.
6. State time and space complexity.

Practice on free platforms such as HackerRank, LeetCode (easy tier) and Codewars.
