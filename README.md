# Python Zero to Hero + Professional English for IT Careers

A free, hands-on roadmap to go from **no coding experience** to **job-ready Python developer**,
while also building **fluent spoken English and presentation skills** for interviews, stand-ups and client meetings.

> Built for learners targeting jobs in IT hubs (Gurugram, Noida, Delhi NCR, Bengaluru, Hyderabad, Pune, Chennai and remote roles).

## How this repo works

| Part | What you get |
|------|--------------|
| `modules/` | 12 Python modules: lesson, runnable examples, exercises, solutions |
| `projects/` | 6 portfolio projects employers like to see |
| `english/` | 90-day speaking plan, presentation framework, phrase bank, interview scripts |
| `career/` | Resume, GitHub, LinkedIn, interview prep, job-search checklist |
| `tools/` | Small CLI tools: speaking-practice tracker, words-per-minute calculator |
| `docs/` | 16-week roadmap and certification guide |

## Quick start

```bash
git clone https://github.com/Neuro-eng/python-zero-to-hero.git
cd python-zero-to-hero
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python modules/01_basics/examples.py
pytest -q                        # runs tests for the solutions
```

## Daily routine (about 2 hours)

| Time | Activity |
|------|----------|
| 60 min | Python: read lesson, type the examples yourself, do exercises |
| 30 min | Project work or LeetCode-style practice |
| 20 min | English: shadowing + speak aloud (see `english/`) |
| 10 min | Log progress: `python tools/speaking_tracker.py log ...` and a git commit |

## Rules for fast progress

1. **Type, never copy-paste.** Typing builds muscle memory.
2. **Commit daily.** A green GitHub contribution graph shows consistency.
3. **Build before you feel ready.** Start projects at module 6.
4. **Speak every day,** even 5 minutes, even to yourself.
5. **Explain what you learn** out loud in English: that is both revision and speaking practice.
